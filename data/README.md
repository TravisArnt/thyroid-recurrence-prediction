# Dataset

This folder contains information related to the dataset used in the project.

## Dataset Name

**Differentiated Thyroid Cancer Recurrence**

## Source

UCI Machine Learning Repository

- **Dataset ID:** 915
- **Dataset link:** https://archive.ics.uci.edu/dataset/915/differentiated+thyroid+cancer+recurrence
- **DOI:** https://doi.org/10.24432/C5632J
- **Licence:** Creative Commons Attribution 4.0 International (CC BY 4.0)

## Dataset Description

The dataset contains:

- 383 patient records
- 16 input features
- 1 binary target variable: `Recurred`

The target variable indicates whether differentiated thyroid cancer recurrence occurred.
